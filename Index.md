Assignment 6.2 — Backgrounds, Borders & Display

Aim


To create three differently styled pricing cards using CSS backgrounds, borders, and rounded corners, and demonstrate the block, inline, and inline-block display properties.


CSS Properties Used

background-color: Sets the background color of an element.

border: Adds an outline around an element.

border-radius: Creates rounded corners.

width and height: Define an element's dimensions.

max-width: Sets the maximum width an element can have.

display: block: Starts on a new line and takes the available width by default.

display: inline: Places elements on the same line; width and height cannot normally be set directly.

display: inline-block: Places elements on the same line while allowing width and height to be set.

Card Designs

Basic: Blue background with a blue border.

Standard: Green background with a green border.

Premium: Purple background with a purple border.

Each card contains a title, description, price, and button.

Files Included

index.html — HTML structure of the pricing cards and display examples.

style.css — CSS styles for backgrounds, borders, dimensions, and display properties.
